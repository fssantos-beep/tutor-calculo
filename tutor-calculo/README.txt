Tutor Inteligente de Cálculo - Web App

Pergunte sobre conceitos de cálculo e receba respostas contextualizadas
Recapitulação automática dos conceitos estudados
Geração de exercícios por nível (básico/intermediário/avançado)
O sistema busca trechos relevantes dos materiais antes de responder


Pré-Requisitos:
python 3.8+
pip 21.0+
Ollama 0.1.0+

Baixe e instale o Ollama LLM LOCAL (MISTRAL:7B):
https://ollama.com/download
